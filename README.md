# CapiLog Demo

Versão web interativa de apresentação, totalmente separada do CapiLog principal.

- Todos os números e registros são fictícios.
- Nenhuma integração com Supabase, Brudam ou dados reais.
- Interatividade local: filtros, busca, alteração simulada de status e abas.
- As alterações simuladas são reiniciadas ao recarregar a página.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar na Vercel

Importe este repositório como projeto Next.js. Nenhuma variável de ambiente é necessária.
